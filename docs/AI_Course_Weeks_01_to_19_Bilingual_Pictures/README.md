# AI Course Weeks 01–19 — Bilingual GitHub-Ready Package

Complete package containing the **Spanish** and **English** editions of the AI course, fully organized for GitHub.

## What is included

### Spanish (`/Spanish`)
- 19 complete infographic images
- 19 text guides in Markdown
- 1 Word document with the 19 posters
- 1 Word text manual with the complete written content
- 1 HTML gallery

### English (`/English`)
- 19 complete infographic images
- 19 text guides in Markdown
- 1 Word document with the 19 posters
- 1 Word text manual
- 1 HTML gallery

## Quick start

- Open `Spanish/gallery/index.html` to browse the Spanish posters.
- Open `English/gallery/index.html` to browse the English posters.
- Upload the whole folder to GitHub to preserve the full structure.
